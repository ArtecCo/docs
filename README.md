# Araha Docs

A small PHP/MySQL private document repository for cPanel shared hosting.

- PDF and image upload, preview and download
- Document names, tags, search and tag filters
- Rename, retag and delete
- PWA install support
- Private storage under `storage/`, denied by Apache rules
- cPanel Directory Privacy as the outer authentication gate

See [INSTALL.md](INSTALL.md) for setup and security verification.
